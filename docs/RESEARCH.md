# ผลการค้นคว้าและขอบเขต — 12 พฤศจิกายน 2026

## ภาษาที่เลือก

ใช้ **S’gaw Karen / กะเหรี่ยงสะกอ (`ksw`)** เป็นจุดเริ่มต้นสำหรับคำขอปกาเกอะญอ ไม่ผสม Pwo, Pa’o, Kayah หรือพม่าเข้าด้วยกัน ต้องให้ผู้ใช้ในชุมชนเป้าหมายยืนยันสำเนียงและระบบเขียนก่อนขยายเป็นเครื่องมือใช้งานจริงในชุมชน

## สิ่งที่ทดสอบได้และข้อจำกัด

1. ไทย → กะเหรี่ยง: ค้นเฉพาะความหมายไทยฉบับร่างที่เพิ่มจาก English gloss 375 รายการ ไม่ใช่แปลไทยทั่วไป
2. อังกฤษ → กะเหรี่ยง: ค้น exact/prefix/substring ของคำและความหมายอังกฤษในฐานข้อมูล วลีที่มีตรงกันจึงคืนเป็นวลี; ผลใกล้เคียงแสดงชัดว่าไม่ใช่คำแปลตรงตัว
3. กะเหรี่ยง → อังกฤษ: ค้นอักษร Unicode; ไทยแสดงเฉพาะ sense ที่มีร่างไทย
4. คำอ่าน: แสดง romanization / IPA เท่าที่ต้นฉบับมี ไม่สร้างคำอ่านไทยขึ้นเอง
5. เสียงขาเข้า: [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) สำหรับไทย/อังกฤษ ขึ้นกับเบราว์เซอร์ สิทธิ์ไมค์ บริการ และเครือข่าย บางเบราว์เซอร์ส่งเสียงไปบริการออนไลน์; ไม่รับรอง offline หรือทุกอุปกรณ์
6. เสียงขาออก: มีเพียง 2 ไฟล์ ไม่สังเคราะห์เสียงพม่าทดแทนกะเหรี่ยง ไม่มี full Karen TTS ในรุ่นนี้
7. ประโยคยาว: ยังไม่แปลทั้งประโยค มี greedy longest-match ช่วยแยกคำกะเหรี่ยง พร้อมแสดงข้อความที่ไม่รู้จักและคำเตือนว่าอาจแบ่งผิด ไม่แต่งคำแปลจากการต่อคำ
8. ชุดข้อมูลดั้งเดิมมีคำศัพท์ซ้ำหลายชนิดคำ/ความหมาย และบางรายการเป็นตัวเขียนไม่มาตรฐาน; คงชนิดคำและป้ายกำกับไว้
9. ข้อมูลภาษาไม่ผ่าน native-speaker review ในโครงการนี้; ภาษาไทยเป็นร่าง AI จึงไม่อ้างเป็นพจนานุกรมไทย–ปกาเกอะญอที่รับรองแล้ว
10. Google Cloud มี [รายการภาษาที่รองรับ](https://docs.cloud.google.com/translate/docs/languages) ให้ตรวจตามบริการและโมเดล รุ่นนี้ไม่ผูกกับ API ใด และไม่อ้างว่า Google Translate รองรับ `ksw` โดยอัตโนมัติ

## การตรวจโดยเจ้าของภาษาในขั้นถัดไป

เลือกชุมชนเป้าหมายและสำเนียง → ทบทวนความหมายไทย 375 รายการ → เพิ่มประโยคใช้จริงที่มีบริบท → บันทึกเสียงเจ้าของภาษาโดยได้รับอนุญาตเผยแพร่ → จัดชุดทดสอบที่ไม่ซ้ำข้อมูลฝึก → ประเมินการสื่อสารก่อนใช้บริการแปลประโยคอัตโนมัติ

เก็บชื่อผู้ตรวจ วันที่ แหล่งอ้างอิง สำเนียง สัญญาอนุญาต และสถานะการตรวจระดับ sense/คลิป หากไม่ทราบ ให้คงสถานะรอตรวจ ไม่ยกระดับเป็น verified เอง

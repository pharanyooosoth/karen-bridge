1 เลือกรูปข้อความ

ถ่ายให้ตรง แสงชัด และครอปเฉพาะข้อความ
ภาพต้นฉบับไม่เกิน 10 MB

ภาพและข้อความอ้างอิงสำหรับช่วยอ่าน

เช่น เลือกภาพตารางเดือนเต็มเป็นภาพอ้างอิง แล้วเลือกภาพคำที่ต้องการอ่านด้านบน ควรมีคอลัมน์อักษร–คำอ่านไทยอยู่แถวเดียวกัน

ข้อความที่บันทึกอยู่เฉพาะเบราว์เซอร์นี้ ไม่แชร์ข้ามเครื่อง API ได้รับภาพและข้อความอ้างอิงเฉพาะเมื่อคุณกดอ่าน/หาคำอ่าน/แปล และใช้พจนานุกรมกะเหรี่ยงสะกอของโครงการช่วยเทียบข้อความตรงกัน

รหัสใช้เฉพาะหน้านี้ ไม่บันทึกในเบราว์เซอร์

ไม่เก็บภาพหรือผลแปลเป็นประวัติ เตรียมภาพเป็น PNG เมื่อขนาดพอ หรือ JPEG คุณภาพสูง อาจย่อขนาดก่อนส่ง ภาพเล็กหรือเบลอยังอาจอ่านผิด

สะพานภาษา

เครื่องมือเริ่มต้นสำหรับเรียนรู้ปกาเกอะญอ
ให้ข้อมูลที่ตรวจย้อนกลับได้ และเปิดทางให้ชุมชนช่วยตรวจแก้

เวอร์ชันนี้ทำอะไรได้บ้าง

  • ค้นคำไทยที่มีในชุดข้อมูล หรือภาษาอังกฤษ ไปยังคำกะเหรี่ยงสะกอ
  • ค้นอักษรกะเหรี่ยง Unicode กลับเป็นอังกฤษ และไทยในรายการที่มี
  • ดูคำอ่านไทยโดยประมาณ พร้อมโรมัน / IPA และฟังเสียงเฉพาะรายการที่มีไฟล์
  • รับคำพูดไทยหรืออังกฤษผ่าน Web Speech API เมื่อเบราว์เซอร์รองรับ
  • บันทึกคำโปรดและดาวน์โหลดไว้ใช้ต่อ

สิ่งที่ยังต้องพัฒนาร่วมกับผู้รู้ภาษา

การแปลประโยคด้วย AI ยังเป็นรุ่นทดลองและต้องเชื่อมต่อบริการก่อน ส่วนเสียงพูดครบทุกคำ ความหมายไทยครบฐานข้อมูล และการรองรับตัวเขียนหรือสำเนียงอื่น ยังไม่พร้อมในรุ่นนี้ การแยกคำเป็นเพียงเครื่องมือช่วยอ่าน ไม่รับรองความหมายทั้งประโยค

เริ่มที่ S’gaw Karen (ksw) ไม่รวม Pwo Karen หรือภาษาอื่นโดยอัตโนมัติ อักษรเก่าที่ไม่ใช่ Unicode และปกาเกอะญอที่เขียนด้วยอักษรไทยยังไม่รองรับ

การใช้ข้อมูลของคุณ

การค้นพจนานุกรมทำงานในเบราว์เซอร์ ไม่มี analytics ส่วนเมนูแปลจากรูปภาพจะส่งภาพหรือข้อความไปเซิร์ฟเวอร์ของเว็บและ OpenAI เฉพาะเมื่อผู้ใช้ยืนยันและกดอ่านหรือแปล ปุ่มไมค์จะเริ่มรับเสียงเมื่อกดเท่านั้น บริการของเบราว์เซอร์อาจประมวลผลเสียงออนไลน์ การเปิดแหล่งอ้างอิงและเล่นเสียงจะเชื่อมต่อเว็บไซต์ภายนอก
